# 🧑‍💼 Employee Management System

## 📄 Description
A desktop application to manage employee records using Java Swing, Awt and MySQL. Includes modules like employee addition, search, update, delete, and check-in/check-out via QR code.

## ✨ Features
- Add/Search/Delete/Update Employee
- Admin login panel
- QR-based attendance system
- MySQL backend integration
- Clean UI with Swing and AWT

## 🛠 Technologies Used
- Java
- Swing
- AWT
- MySQL
- NetBeans IDE

## 🚀 How to Run
1. Open the project in NetBeans
2. Ensure MySQL is running and database is configured
3. Run the main class to launch the UI
4. or
5. download the .jar file from dist folder and run on system
